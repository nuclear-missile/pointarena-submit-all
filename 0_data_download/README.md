# Data Download Guide

All dataset download commands.

## 1. Raw Training Datasets (4 sources)

```bash
# PixMo-Points (~1.85M rows, primary data source)
hf download allenai/pixmo-points --repo-type dataset --local-dir ./raw_data/pixmo_points

# RoboPoint (~667K rows)
hf download wentao-yuan/robopoint-data --repo-type dataset --local-dir ./raw_data/robopoint

# RefSpatial (~1.8K rows)
hf download JingkunAn/RefSpatial --repo-type dataset --local-dir ./raw_data/refspatial

# Where2Place (~100 rows)
hf download FlagEval/Where2Place --repo-type dataset --local-dir ./raw_data/where2place

# China mirror acceleration (optional):
# export HF_ENDPOINT=https://hf-mirror.com
```

## 2. PointArena Evaluation Data

```bash
hf download PointArena/pointarena-data --repo-type dataset --local-dir ./eval_data

# Contains:
#   val_pointarena.jsonl  (982 evaluation samples)
#   images/affordance/    (~40 images)
#   images/counting/      (~40 images)
#   images/reasoning/     (~40 images)
#   images/spatial/       (~40 images)
#   images/steerable/     (200 images)
#   masks/{5 categories}/ (ground truth masks)
```

## 3. Model Weights

```bash
# Molmo2-8B (auto-downloaded by transformers, ~16GB):
#   Automatically downloaded from allenai/Molmo2-8B on first use

# Qwen3-8B (for local data pipeline):
hf download Qwen/Qwen3-8B --local-dir ./models/Qwen3-8B

# MolmoPoint-8B (alternative backbone, optional):
#   Automatically downloaded from allenai/MolmoPoint-8B on first use

# SAM3 ONNX (for Steerable pipeline):
#   Manual download, place at ./models/sam3.onnx
```

## 4. Processed Data (generated by pipelines, no download needed)

Automatically generated after running the data pipelines:
- `data/cache/pointarena_rewritten_training_summary_steerable_d.json` (168MB)
- `pointarena_extract/` (Gemini output)
- `clean_3types_local/` (Qwen output)
- `make_steerable1/sam_clean/outputs/` (Steerable output)

## Recommended Directory Structure

```
PointArena/
├── raw_data/              # Raw HF datasets
│   ├── pixmo_points/
│   ├── robopoint/
│   ├── refspatial/
│   └── where2place/
├── eval_data/             # PointArena evaluation data
│   ├── val_pointarena.jsonl
│   ├── images/
│   └── masks/
├── models/                # Model weights
│   ├── Molmo2-8B/        # Auto-downloaded
│   ├── Qwen3-8B/         # Manual download
│   └── sam3.onnx         # Manual download
├── processed_data/        # Pipeline outputs
├── checkpoints/           # Training checkpoints
│   └── checkpoint.pt     # 3.8GB
└── outputs/               # Training outputs
```

## Installing Download Tools

```bash
# Install HuggingFace CLI and datasets (Python 3.10+):
pip install --user huggingface_hub datasets

# Ensure ~/.local/bin is in PATH:
export PATH="$HOME/.local/bin:$PATH"

# Verify installation:
hf --version

# Or use python3 -m:
python3 -m pip install --user huggingface_hub datasets

# If pip is not installed, install it first:
# curl -s https://bootstrap.pypa.io/get-pip.py | python3

# China mirror acceleration (optional):
# export HF_ENDPOINT=https://hf-mirror.com

# Or use git-lfs to download manually:
git lfs install
git clone https://huggingface.co/datasets/allenai/pixmo-points
```

**Notes:**
- If `hf` is not in PATH, use `python3 -m huggingface_hub` or add `~/.local/bin` to PATH.
- The `download_raw_datasets.py` script depends on the `datasets` package.
- The `download_pointarena_eval.py` script depends on the `huggingface_hub` package.

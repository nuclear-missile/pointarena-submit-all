# Model Training: AttnRes + ABC (Innovation 2 + 3)

AttnRes (Gated Attention Residual) + ABC three-branch point coordinate encoding. Complete training and evaluation pipeline for the PointArena submission.

---

## Overview

This module trains Molmo2-8B-based models using:

- **AttnRes**: Gated attention residual connections that allow the model to revisit anchor context across deeper layers
- **ABC Three-Branch Encoding**: Three approaches (A, B, C) for injecting point coordinates into the vision-language model, with progressive accuracy improvements
- **Steerable + AttnRes Training**: Combines steerable data with the AttnRes architecture for the steerability category

The final submission uses category-level routing, selecting the best expert per task type.

---

## Architecture Details

### AttnRes (Attention Residual)

```
H_i = H_i + tanh(alpha) * AttnRes(H_i; H_{i-3:i-1})
```

- Injected every 4 transformer layers
- Gate `alpha` is initialized to 0 (identity mapping at training start)
- Cross-block softmax attention aggregates historical block states
- **Used only for Steerability and Counting** (ablation studies show it harms non-steerable categories)
- Implemented in `arch/arch_attnres.py`

### ABC Three-Branch Point Encoding

| Branch | Method                        | Key Modules                                                                 | Accuracy |
|--------|-------------------------------|-----------------------------------------------------------------------------|----------|
| A      | Text coordinate appending     | None (coordinates appended as text tokens)                                 | 72.3%    |
| B      | PointMLP + ViT                | PointCoordinateMLP (2 -> 4096) + ViTFeatureExtractor (layers [8, 12, 16])  | 75.5%    |
| C      | CoordMap CNN                  | B + CoordMapEncoder (100x100x4 heatmap CNN -> 16 tokens)                   | **77.0%** |

- Visual encoding drives the accuracy improvements; additional correction rounds improve stability rather than peak performance
- Implemented in `arch/arch_point_injection.py`

## Scripts to Run

### Experiment A: Text Coordinate Correction (Baseline)

```bash
cd 4_model_training/
export PYTHONPATH=$PWD:$PYTHONPATH

python train/train_exp_a.py \
    --model_path allenai/Molmo2-8B \
    --summary_path ../data/cache/pointarena_rewritten_training_summary_steerable_d.json \
    --output_dir ../outputs/exp_a \
    --max_steps 20000 \
    --lr 2e-4 \
    --context_len 2048
# Expected: ~72.3% overall
```

### Experiment B: PointMLP + ViT

```bash
python train/train_exp_b.py --exp B \
    --model_path allenai/Molmo2-8B \
    --summary_path ../data/cache/pointarena_rewritten_training_summary_steerable_d.json \
    --output_dir ../outputs/exp_b \
    --noise_sigma 100.0 \
    --lr 1e-4
# Expected: ~75.5% overall
```

```bash
python train/train_exp_c.py --exp C \

    --output_dir ../outputs/exp_c \
```

### Steerable + AttnRes Training

```bash
python train/train_steerable_attnres.py \
    --model_path allenai/Molmo2-8B-attnres \
    --summary_path ../data/cache/pointarena_rewritten_training_summary_steerable_d.json \
```

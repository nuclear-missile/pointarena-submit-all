Reference documentation for all training checkpoints, model weights, datasets, and data flow used in the PointArena project.

## Training Checkpoints

### Final Submission Checkpoint

- **Path**: `~/PointArena/checkpoints/checkpoint.pt` (3.8 GB)
- **Contents**: LoRA adapters for all 4 experts + architecture submodules + metadata
- **Format**: PyTorch checkpoint dictionary

```python
{
    "lora_adapters": {"C": {...}, "B": {...}, "steer": {...}, "counting": {...}},
    "lora_configs": {"C": {...}, "B": {...}, "steer": {...}, "counting": {...}},
    "arch_modules": {...},
    "meta": {...}
}
```

## Data Flow

```
Raw HF Datasets (2.5M rows)
  -> Cleaning (reclean_from_raw_full.py)
  -> Gemini Pipeline -> 24,415 trainable rows (5 categories)
  -> Qwen Pipeline -> 3 categories + Counting supplementary data
  -> Steerable Pipeline -> Anchor relative-direction data
  -> Summary Cache Merge -> summary_steerable_d.json
  -> Balanced Sampling -> Training set (3,815 / 12,680 / 17,500 rows)
  -> Training Loop -> LoRA Adapters
  -> Checkpoint Merge -> checkpoint.pt (3.8 GB)
  -> Category Routing Evaluation -> 77.2%
```
